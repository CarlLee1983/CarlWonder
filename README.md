# CarlWonder

用精彩敘事探索世界奇異知識的繁體中文靜態網站：從三星堆、埃及金字塔等古文明題材開始，再延伸到自然與科學。每篇篇章都查核來源，清楚區分已知證據、推論、傳說與未知，並附「親子共學」，提供故事開場、觀察提問與家庭探索活動。

沿用 CarlStack、CarlKitchen、CarlEnglish 的模式：內容在本地製作、以 Git 管理、靜態部署到 Cloudflare（`carlwonder.gravito.dev`），不做後台。

## 狀態

閱讀頁與三篇樣章已完成，正式建置會列出安提基特拉機械、吉薩金字塔與三星堆；每篇附證據說明、參考資料與親子共學。站主合併發布 PR 後由 GitHub Actions 觸發部署。用語見 `CONTEXT.md`，決策見 `docs/adr/`。
