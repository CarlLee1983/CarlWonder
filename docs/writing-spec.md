# 編寫規格

本文件規定篇章怎麼寫。用語以 [`CONTEXT.md`](../CONTEXT.md) 為準，題材的選擇與排序見 [`topic-map.md`](topic-map.md)。研究依據在 `research/evidence-grading` 與 `research/family-reading` 兩個分支的研究文件；沒有研究依據、由本專案自訂的規則，都在條文裡註明「自訂」。

## 篇章結構

篇章依下列順序組成，同一頁呈現：

1. 標題
2. 深入正文
3. 還不知道的事
4. 證據說明
5. 參考資料與最後查核日期
6. 親子共學：故事開場、觀察提問、家庭探索活動

### 標題

格式是「題材：問題」，例如「三星堆：誰做了這些大眼面具？」。冒號後面的問題，就是正文要回答、或要承認至今沒有答案的核心問題。不用「驚人」「顛覆」「震驚」這類字眼。

### 深入正文

- 讀者是大人，語氣是好奇、說故事的口吻，不寫成教科書。
- 篇幅 3,000–5,000 字。
- 採自由敘事，不切成「已知、推論、傳說」三個區塊，但必須包含：
  - 開頭用一個具體場景或物件破題；
  - 至少一段把流行說法和證據放在一起對照。
- 不放註腳編號。主張與來源的對應寫在證據說明裡。
- 不寫「科學家都嚇呆了」「科學無法解釋」這類句型。

### 還不知道的事

正文最後一節，標題固定為「還不知道的事」。至少列一個至今沒有答案的問題，並寫出目前卡在哪裡，例如缺了哪個遺址、哪份報告還沒公布。

## 證據等級

篇章中的主張分四級。這是單軸設計，取捨見 [ADR 0003](adr/0003-single-axis-evidence-levels.md)。

| 等級 | 意思 |
|---|---|
| 已知 | 有出土實物、測年或文獻直接支持 |
| 推論 | 學者依據證據提出的解讀，學者意見不同的情況也屬於這一級 |
| 傳說 | 一個故事；一定要交代它出自哪本古書、哪個族群的口傳，或哪個現代說法 |
| 未知 | 至今沒有答案的問題 |

### 詞表

正文用句內措辭表達等級，不加徽章或符號。措辭只能從下表選；要用表外的說法，先修訂本表。

| 等級 | 可用措辭 | 禁用 |
|---|---|---|
| 已知 | 直接陳述；「出土了」「測年顯示」 | 把結論推過頭的寫法，例如「證明了外星人」 |
| 推論 | 「學者推測」「可能」「多數學者認為」「意見不同」 | 把推論寫成直接陳述 |
| 傳說 | 「傳說」「相傳」「古書記載」「有一種說法」，並寫出出處 | 不寫出處的「據說」 |
| 未知 | 「還不知道」「至今沒找到」「仍有爭論的是」 | 「科學無法解釋」 |

### 證據說明

放在「還不知道的事」之後的表格，列出 5–10 個主要主張。每一列有三欄：主張、證據等級、參考資料編號。

## 來源

- 每個「已知」主張，至少要有一個一手或權威來源：考古簡報、同儕審查期刊、博物館或大學。
- 只讀到摘要的來源，不能單獨撐起一個「已知」主張。
- 新聞媒體只能用來說明「最近有新發現」，而且必須追到它引用的原始論文，參考資料列的是原始論文。
- 維基百科只拿來找線索，不列入參考資料。
- 內容農場、YouTube 與偽考古網站，只在描述流行說法時引用，並標明它是流行說法的出處。

### 參考資料

依 [ADR 0002](adr/0002-sources-are-public.md)，篇章頁面公開列出參考資料。格式是編號清單，每一條包含：作者、年份、標題、出處（期刊或機構）、連結、查閱日期。清單之後寫「最後查核：YYYY-MM-DD」。

### 查核紀錄

每篇篇章在 `docs/research/<slug>.md` 有一份查核紀錄，內容固定包含：

1. 每個來源採用了哪些主張、查核日期，以及讀的是全文還是只有摘要。
2. 證據說明裡每一條主張的依據，標上 [已查證]、[摘要層級] 或 [推論]。
3. 排除了哪些說法，以及排除的原因。
4. 已知缺口。
5. 證據等級的變動紀錄：哪條主張從哪一級改成哪一級、在哪一天改。

## 圖片

依 [ADR 0001](adr/0001-imagined-illustrations-are-labelled.md)，讀者要能一眼分辨圖是不是實物。

### 圖片類型與標記

| 圖片類型 | 是什麼 | 標記 |
|---|---|---|
| 實物照片 | 文物或遺址本身的照片 | 無 |
| 研究重建圖 | 學者依證據畫的復原圖或掃描影像 | 「研究重建」 |
| 複製品照片 | 依實物做的複製品的照片 | 「複製品」 |
| 想像圖 | CarlWonder 自己生成或繪製的插圖 | 「想像圖」 |

- 標記是壓在圖片左上角的文字膠囊，由頁面疊上去，不燒進圖檔。
- alt 一律必填，描述圖中實際看得到的東西；非實物照片的 alt 以「想像圖：」「研究重建：」「複製品：」開頭。
- 觀察提問的錨點只能用實物照片。

### 圖說

- 想像圖的圖說固定兩句：「依據：〈證據〉〔參考資料編號〕。想像部分：〈哪些是猜的〉。」
- 研究重建圖的圖說寫明是哪個團隊、哪篇論文的重建；複製品照片寫明複製品的製作者。
- 非自製的圖，圖說末行寫「照片：作者／機構，授權」，作者連到原始檔案頁，授權連到授權條款；裁切過的加註「經裁切」。圖片出處只寫在圖說，不列入參考資料。

### 想像圖的畫風

- 必須是一眼看得出的插畫風格（例如水彩、版畫線條），不得用擬真攝影風格。
- 可以畫場景（祭祀現場、工匠作業），但已有實物照片的文物，不得改用想像圖呈現。

### 可接受的授權

依 [ADR 0004](adr/0004-permanently-non-commercial.md)，網站永久非營利，所以 NC 條款可用。

- 可用：CC0、公有領域、CC BY、CC BY-SA、CC BY-NC、CC BY-NC-SA。
- 不可用：任何 ND 條款；「保留所有權利」的圖，除非取得書面授權，授權信存在 `docs/research/<slug>.md`。
- 授權逐檔查核，以原始檔案頁為準，不看分類頁或聚合網站。

### 圖片規格

- 放在 `content/chapters/<slug>/`，檔名描述圖片內容。
- 一律 WebP，長邊 1536 px，單檔不超過 300 KB。
- 想像圖固定 3:2；實物照片保留原比例，只縮小不放大。
- 規格與必填欄位在建置時檢查，不合格就擋下。

### 圖片紀錄

每篇在 `docs/research/<slug>.md` 的「圖片」一節記錄所有圖：

- 想像圖：生成日期、工具與模型、完整提示詞、依據的參考資料編號、成品路徑。
- 其他圖：原始檔案頁網址、作者、授權、查核日期、成品路徑。

## 親子共學

對象是家長陪讀的 6–10 歲孩子，不分年齡版本。

- 不出現證據等級的名稱。
- 不寫「研究證明」：6–10 歲的親子共讀方法沒有直接的效果研究，只能寫「參考 Project Zero 的思考例程」這類說法。

### 故事開場

- 一段家長可以照稿唸的完整口述稿，450–600 字，大約 1.5–2 分鐘。字數原本依 150–200 字／分推估為 3 分鐘；2026-10-15 站主實際朗讀安提基特拉的故事開場，490 字約 90 秒（約 327 字／分），決定維持字數、改寫時間（紀錄見 `docs/research/antikythera-mechanism.md`〈朗讀計時紀錄〉）。
- 一氣呵成，中間不插提問。
- 只用已知的材料，或明確說是傳說的故事；不把推論講成事實。
- 不描寫死亡、獻祭、戰爭的細節，必要時用「古人把珍貴的東西獻給神」這種程度的說法（自訂規則：研究沒有找到這個年齡的內容分寸依據）。

### 觀察提問

- 每篇指定一張實物照片當錨點，不能用想像圖。
- 分三段：
  - **看到**（對應已知）：孩子看照片，說出看到的東西。
  - **覺得**（對應推論）：孩子先猜，家長再說學者怎麼猜。
  - **好奇**（對應未知）：孩子提出還想知道的事。
- 每一段給一題基本題，加一題標示「大一點的孩子」的延伸題，由家長自己挑。
- 家長提示語：用孩子的回答再往下延伸，接著問一句或補一個細節（借用 PEER 的擴充作法）。
- 碰到死亡或暴力相關的題材時，在家長提示裡加一句「孩子問起時可以怎麼說」。

### 家庭探索活動

每篇一個活動，欄位如下：

| 欄位 | 規則 |
|---|---|
| 名稱 | — |
| 所需時間 | 不超過 30 分鐘 |
| 材料 | 列出全部材料 |
| 步驟 | 不超過 6 步 |
| 大人要做什麼 | 必填 |
| 和篇章的關係 | 一句話，連回正文的某個已知或未知 |

禁用清單，不能設計成活動：

- 強力磁鐵（釹磁鐵）
- 需要拆卸鈕扣電池
- 直視太陽：觀察太陽一律用投影法，並寫明禁止直視
- 明火與加熱
- 混合清潔劑或化學品；如果會噴濺，寫明戴護目鏡
- 8 歲以下孩子用氣球；如果用了氣球，寫明大人在場、破片立刻收走

材料中有小零件、小珠、彈珠時，提醒家長收好，不讓年幼的弟妹拿到。

## 發布前檢查清單

開 draft PR 前逐項確認：

- [ ] 標題符合「題材：問題」，沒有誇張字眼
- [ ] 每個「已知」都有一手或權威來源，且不是只靠摘要
- [ ] 措辭都在詞表內
- [ ] 有「還不知道的事」與證據說明
- [ ] 參考資料欄位齊全，有最後查核日期
- [ ] 非實物照片都有類型標記，想像圖有「依據／想像部分」圖說
- [ ] 每張非自製的圖都有出處與授權，授權在可用清單內
- [ ] 想像圖是插畫風格，沒有取代已有實物照片的文物
- [ ] `docs/research/<slug>.md` 的「圖片」一節記錄了每張圖
- [ ] 故事開場在 450–600 字之間，沒有把推論講成事實，沒有死亡或暴力的細節
- [ ] 觀察提問的錨點是實物照片
- [ ] 活動沒有用到禁用清單的項目，「大人要做什麼」有填
- [ ] `docs/research/<slug>.md` 查核紀錄已建立

## 更新已發布的篇章

不定期重查。知道有新的同儕審查論文或重大發現時，重新查核，更新正文、證據說明與查核紀錄，改最後查核日期；如果有主張的證據等級改變，在查核紀錄記下變動。
