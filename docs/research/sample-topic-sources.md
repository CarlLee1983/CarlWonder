### 4. 圖片授權

- **三星堆博物館官網**：找不到任何圖片授權或再利用聲明 **[未查到]**。應視為保留所有權利，未經館方書面授權不得使用。
- **Wikimedia Commons**：用 Commons API 讀取各檔案的 `LicenseShortName` 欄位 **[已查證，2026-10-15]**：
  - `Category:Bronze_in_Sanxingdui` 前 40 個檔案中，CC0 34 個、CC BY-SA 4.0 5 個、公有領域 1 個。CC0 的主要是 Gary Todd 從 Flickr 上傳的系列（檔名帶 Flickr 編號，例如 `Ancient Bronze Water Vessels (9950975845).jpg`）。
  - `Category:Gold_in_Sanxingdui`：CC BY-SA 4.0 19 個、CC0 18 個、公有領域 1 個、CC BY 3.0 1 個；例如金面具 `G0LD MASK in Sanxingdui 20161122.jpg` 是 CC BY-SA 4.0（作者 Tyg728）。
  - 授權逐檔不同，分類頁本身不給授權，必須逐檔讀描述頁。CC0 可以直接用；CC BY-SA 4.0 要署名，衍生作品也要用相同授權。
- **中國著作權法與 Commons**：Commons 的中國版權規則頁說明，2021-06-01 修法後，公共場所的立體作品（含雕塑）可以拍攝（第 24 條第 10 款），但頁面沒有說明博物館室內展品算不算「公共場所」**[已查證：頁面確實沒寫]**。三千年前的器物本身沒有著作權，風險主要在照片的攝影著作權，所以授權要看攝影者 **[推論]**。
- **新聞機構照片**（新華社、人民網、China Daily）：都聲明未經授權不得轉載 **[推論：只看過人民網的聲明]**，不得使用。

- **大都會藝術博物館**：自 2017-02-07 起，館方認定為公有領域的作品圖像以 CC0 釋出，頁面上帶 Open Access 圖示 **[推論：政策頁讀取被擋，內容由搜尋摘要轉述]**。用 Met Collection API 實測 **[已查證，2026-10-15]**：
  - 每件藏品有 `isPublicDomain` 欄位，必須逐件確認。例如以「Khufu」搜尋，三件胡夫名號聖甲蟲（555206、558600、555114）都是 `false`，19 世紀照片〈Pyramides de Gizèh〉（291695）是 `true`。
  - 舊的 `/public/collection/v1/search` 已在 2026-10-01 停用（HTTP 410），改用分頁式的 `/public/collection/v1.1/search?offset=&limit=`；`/v1/objects/{id}` 仍然可用。若之後要寫抓圖腳本，要用新端點。
- **大英博物館**：2020 年起大部分館藏圖像以 CC BY-NC-SA 4.0 提供，只限非商業使用，必須署名，衍生作品也要用相同授權；第三方權利、文化敏感與人類遺骸相關的圖像不在授權範圍內 **[推論：政策頁讀取被擋，內容由 2020 年報導與搜尋摘要轉述]**。網站若有廣告或收費，就不能算非商業，使用前要確認。
- **Wikimedia Commons**：`Category:Great_Pyramid_of_Giza` 前 40 個檔案的授權有 CC BY-SA 4.0（19）、CC BY-SA 3.0（5）、CC BY 2.0（5）、CC BY 4.0（4）、公有領域（3）等 **[已查證，Commons API]**。埃及沒有涵蓋商業使用的全景自由，但古代建築早已沒有著作權，風險只在照片本身 **[推論]**。
- **AERA、Digital Giza**：頁尾都只寫「All rights reserved」，沒有開放授權條款 **[已查證]**。要用圖必須向單位申請。

---

## 三、給篇章撰寫的建議

1. 文物照片優先用 Commons 的 CC0 檔案（三星堆有大量 Gary Todd CC0 照片），其次是 Met 中 `isPublicDomain: true` 的藏品；CC BY-SA 圖要在圖說附作者與授權，符合 ADR 0001 的出處要求。
2. 大英博物館的 CC BY-NC 圖，在確認網站屬非商業用途之前先不要用。
3. 三星堆的「祭祀坑」一詞，可依簡報改寫成「祭祀區的器物埋藏坑」，並在推論欄說明命名之爭。
4. 標成「推論」或「未查到」的條目，寫進篇章前要先回到一手來源補查，尤其是三星堆 1999 年正式報告、梅勒日誌刊本，以及 Met、大英博物館的政策頁原文。
