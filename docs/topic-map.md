# 主題地圖

本文件是內部規劃文件，記錄題材的分類、入選標準、清單與排序；網站的瀏覽方式另行決定，不受本文件約束。用語以 [`CONTEXT.md`](../CONTEXT.md) 為準。篇章是否已發布以 repo 內容與已合併的 PR 為準，本文件不記錄進度。

## 分類

每個題材對應一篇篇章；太大的題材拆成數個各自成立的題材，不使用「系列」。

- **領域**（主分類，也是擴張順序）：古文明 → 自然 → 科學。
- **地區**：台灣、東亞、南亞、西亞、北非、地中海、歐洲、美洲、大洋洲。台灣不併入東亞。
- **奇異類型**（每個題材只標一個主類型）：未解之謎、超前技術、流行迷思、異常現象（後者留給自然與科學領域）。

## 入選標準

三項全部符合才排入清單：

1. 有可查的一手或權威來源撐起事實核心，不只有傳說。
2. 有真正的未解問題，或有可以拿來和證據對照的流行說法。
3. 能設計出 6–10 歲孩子在家做得到且安全的家庭探索活動。

只符合前兩項的題材列為候補題材，不排序。

## 排序原則

1. 三篇樣章固定排在最前。
2. 相鄰兩篇不可同地區，也不可同主類型。
3. 每連續 4 篇至少一篇和台灣或東亞有關。
4. 能寫成可唸故事的題材往前排。

新增題材時依同一套原則重排。
