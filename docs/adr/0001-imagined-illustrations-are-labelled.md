# 想像插圖必須在頁面上標示為想像圖

篇章會用生成或繪製的插圖重建古文明場景，但讀者（尤其是孩子）很容易把重建圖當成出土實物。我們決定：每張想像插圖在頁面上帶有可見的「想像圖」標記，圖說寫明依據哪些證據、哪些部分是想像；文物與遺址照片只用授權清楚的來源並附出處與授權，兩類圖在版面上一眼可分。這刻意與 CarlKitchen 禁止頁面文案提及 AI 的做法相反：那裡的插圖只是示意菜色，這裡的插圖可能被誤當成考古證據。

**Falsified if:** 網站不再使用任何想像插圖，或 `docs/writing-spec.md` 的圖片規則改為不區分想像圖與實物照片。
