# 證據等級用單軸四級，只用句內措辭標示

篇章要讓讀者分辨哪些是已知證據、哪些是推論、哪些是傳說、哪些至今未知。IPCC 把確定程度拆成「證據多寡 × 學界共識」兩軸，表達更精確；維基百科一類的作法則在句中加行內標籤。我們決定只用一條軸：已知、推論（學者意見不同也算推論）、傳說、未知。正文只用固定詞表裡的句內措辭表達等級，不加徽章或符號，另在正文之後放一張證據說明，列出主要主張的等級與來源。雙軸對大人精確，但讀者記不住，親子共學也無法沿用；行內徽章會打斷敘事，而敘事正是這個網站的核心。這樣做的代價是：同屬「推論」的主張，強弱只能靠措辭區分，例如「多數學者認為」比「可能」強。

**Falsified if:** `docs/writing-spec.md` 的證據等級改成兩軸或多於四級，或允許正文使用行內標記。
