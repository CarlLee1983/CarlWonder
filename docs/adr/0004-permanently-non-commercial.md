# CarlWonder 永久非營利

篇章需要大量文物照片，但許多可用來源只許非營利使用：大英博物館的館藏圖像與 *Almagest* 銘文特刊是 CC BY-NC，希臘 Law 4858/2021 第 46 條則要求營利目的使用國有古物影像前，先向 ODAP 申請許可並付費。我們決定 CarlWonder 永久非營利：不放廣告、不接贊助、不販售、不做付費內容。替代方案是「暫不營利、保留日後變現」，但那樣所有 NC 素材與希臘古物照片都會變成日後必須撤換的負債，實務上等於現在就得照營利標準選圖。

因此，`docs/writing-spec.md` 接受 CC BY-NC 與 CC BY-NC-SA，安提基特拉機械等希臘國有古物的照片也不向 ODAP 申請。後者是推論：我們只讀到 Commons 對該法條的摘要，原文 PDF 下載失敗，沒有確認教育或非營利用途的界線（見 `research/antikythera-sources` 分支）。

**Falsified if:** 網站出現廣告、贊助、販售或付費內容，或 `docs/writing-spec.md` 的可接受授權不再包含 NC 條款。
